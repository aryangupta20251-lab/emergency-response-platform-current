# Emergency Response Platform

Frontend-only starter for an Emergency Response After Road Accidents platform.

## Current scope
Tasks 1–5 only:
- Development/project setup
- Design tokens
- Reusable UI components
- Navigation and route structure

No backend, database, real authentication, real maps, or production API integration is included yet.

## Web
```bash
cd web
npm install
npm run dev
```

## Mobile
```bash
cd mobile
npm install
npx expo start
```

## Design source of truth
The supplied Emergency Response Platform design image defines the visual language. The implementation uses its palette, typography hierarchy, spacing, rounded cards, status colors, and navigation style.
